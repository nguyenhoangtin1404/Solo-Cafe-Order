# Wireframes — All Phases

> Layout phác thảo bố cục màn hình. Mobile-first (390px).
> `[ ]` = button, `[___]` = input field, `{img}` = hình ảnh, `(x)` = radio/checkbox

---

# Phase 1 — QR Menu MVP

## Navigation Flow

```
[Khách]                              [Owner]
   │                                    │
Scan QR                              /login
   │                                    │
/menu ──────────────────────────── /dashboard
   │  chọn món                          │  đổi status

/cart                            Product Form
   │  đặt hàng

   │  theo dõi
```
